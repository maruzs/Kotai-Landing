Para el POS de Nexo, esta es la comparación práctica:

| Componente         | Mínimo funcional                    | Recomendado económico     | Ideal                                  | Evitar                                       |
| ------------------ | ----------------------------------- | ------------------------- | -------------------------------------- | -------------------------------------------- |
| **CPU**            | Intel i3 4ª generación o AMD A8/A10 | Intel i3 6ª–8ª generación | Intel i5 6ª–10ª generación o Ryzen 3/5 | Atom, Celeron muy antiguos, Pentium antiguos |
| **Ejemplos Intel** | i3-4130, i3-4150, i5-4570           | i3-6100, i5-6500, i5-7500 | i5-8500, i5-9500, i5-10400             | i3 de 1ª–2ª generación                       |
| **RAM**            | 8 GB                                | 16 GB                     | 16 GB                                  | 4 GB                                         |
| **Tipo RAM**       | DDR3 aceptable                      | DDR4 preferible           | DDR4                                   | DDR2                                         |
| **Almacenamiento** | SSD 128 GB                          | SSD 240/256 GB            | SSD 480/512 GB                         | HDD como disco principal                     |
| **Gráficos**       | Integrados                          | Integrados                | Integrados                             | GPU dedicada innecesaria                     |
| **Red**            | Ethernet 100/1000 Mbps              | Ethernet Gigabit + Wi‑Fi  | Ethernet Gigabit + Wi‑Fi 5/6           | Sólo Wi‑Fi débil                             |
| **Sistema**        | Windows 10 o Linux compatible       | Windows 10/11 o Linux     | Windows 11 o Linux                     | Windows 7 sin soporte                        |

### Diferencias de RAM

| Configuración  | Evaluación para POS                            |
| -------------- | ---------------------------------------------- |
| 4 GB DDR3/DDR4 | Funciona con limitaciones; no recomendable     |
| 8 GB DDR3      | Aceptable para una caja sencilla               |
| 8 GB DDR4      | Mejor que 8 GB DDR3 por plataforma más nueva   |
| 12 GB DDR3     | Muy funcional; supera a 8 GB DDR4 en capacidad |
| 16 GB DDR3     | Suficiente, aunque con plataforma antigua      |
| 16 GB DDR4     | Mejor equilibrio y mayor vida útil             |
| 32 GB          | innecesario para un POS individual             |

### Diferencias de almacenamiento

| Unidad              | Resultado                                                          |
| ------------------- | ------------------------------------------------------------------ |
| HDD 500 GB          | Funciona, pero arranque y actualizaciones serán lentos             |
| SSD SATA 120/128 GB | Suficiente para POS                                                |
| SSD SATA 240/256 GB | Recomendación económica                                            |
| SSD SATA 480/512 GB | Ideal si la diferencia de precio es baja                           |
| NVMe                | Excelente, pero no aporta mucho frente a un SSD SATA para este uso |

### Clasificación rápida

| Equipo                             | Veredicto                                             |
| ---------------------------------- | ----------------------------------------------------- |
| i3 antiguo + 8 GB + HDD            | Sólo comprar si es muy barato y permite cambiar a SSD |
| i3 4ª gen + 12/16 GB + SSD         | Buena compra económica                                |
| AMD A8-7600B + 12 GB + SSD         | Adecuado para POS                                     |
| i3 6ª gen + 8 GB + SSD             | Muy buena compra económica                            |
| i5 6ª/7ª gen + 8 GB + SSD          | Muy bueno; ampliar a 16 GB si es barato               |
| i5 8ª gen o superior + 16 GB + SSD | Ideal, pero probablemente innecesario                 |
| Celeron/Atom + 4 GB                | Evitar                                                |

Mi recomendación concreta para Nodo sería:

**Intel i3 de 6ª generación o superior, 8 GB de RAM, SSD de 240/256 GB y Ethernet.**

Si aparece un equipo más antiguo con **12 o 16 GB y SSD** a buen precio, también sirve perfectamente. La prioridad de compra es:

1. SSD en buen estado.
2. Ethernet y USB suficientes.
3. 8 GB o más de RAM.
4. CPU i3/i5 o AMD A8/Ryzen.
5. Garantía del reacondicionado.
6. Tipo DDR3 o DDR4, que es secundario para este uso.
